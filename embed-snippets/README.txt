ERICA 통합 학사편람 개별 메뉴 삽입용 HTML

대상 홈페이지: https://yoorhi816.github.io/erica-academic-handbook/
구성: 제목 2·제목 3 수준 메뉴 42개 + 학과별 View 1개 = 총 43개
참고: 삭제 요청된 4+1학년제 페이지는 포함하지 않았습니다.

스크롤 안정화 방식:
- 본문 문서(.doc)의 실제 하단 위치를 기준으로 높이를 전달합니다.
- 부모 페이지는 전달받은 높이가 실제 높이와 달라질 때만 iframe 높이를 바꿉니다.
- 기존의 매회 10px 가산을 제거하여 페이지가 계속 길어지는 현상을 방지했습니다.
